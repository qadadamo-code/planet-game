# Planet Messenger

A walkable tiny planet for [Planet — Creative Marketing](https://theplanetco.com). Live at https://www.game.theplanetco.com

Static site: `index.html` + `content.js` (all copy, Arabic/English) + `game.js` (three.js r128) + `models/` (AI-generated GLB models).
Run locally: `python3 -m http.server` then open http://localhost:8000
